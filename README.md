# OpsFlow

> Enterprise Workforce & Operations Management Platform.

OpsFlow is a multi-tenant enterprise SaaS platform for managing workforce operations, projects, tasks, approvals, time, reporting, and organizational workflows.

## Technology

### Backend
- .NET 10
- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server
- Redis
- RabbitMQ

### Frontend
- Next.js
- React
- TypeScript

### Engineering
- Docker
- GitHub Actions
- OpenTelemetry
- Unit Testing
- Integration Testing
- Architecture Testing

## Architecture

OpsFlow follows a modular architecture with explicit domain boundaries and a dependency direction that keeps business logic independent from infrastructure concerns.
